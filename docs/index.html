Android 8.0 or newer. No root needed. Take the arm64-v8a file.

The same Voidcord, on a phone

This is not a rewrite. It is the same server, the same API routes, the same settings screens, the same startup animation and the same Vencord layer as the desktop version. Only what went through Electron had to be replaced.

How it works

On a computer, Voidcord is a local server with an Electron window in front of it, and Electron makes the Discord client believe it is talking to discord.com. A WebView cannot redirect a domain name, so the client is served from http://127.0.0.1 — which Chromium treats as a secure origin — and Node.js runs inside the app itself, through nodejs-mobile. 

WebView ──► http://127.0.0.1:<port>/app ──► Voidcord server (Node) ──► Discord

What does not work yet

Some of this is Voidcord, some of it is Discord. Discord deliberately cuts features out of its mobile web client: voice, file uploads and the GIF picker are not ours to give back. Screen sharing has no equivalent in a WebView, game detection reads Windows processes, and Android requires you to confirm an APK install yourself — so updates are announced rather than applied.
